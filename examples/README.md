# Examples

This directory has two kinds of examples.

## Reproducible examples (`examples/generated/`)

Each directory under `examples/generated/` carries a `.bootstrap-iac.yaml`
config and is generated by the CLI from that config. They stay in sync with the
templates and the generator, and CI checks them.

- Regenerate: `python scripts/build_examples.py`
- Verify (CI runs this): `python scripts/build_examples.py --check`

| Example | Config | Output |
|---------|--------|--------|
| `generated/azure-terragrunt` | Azure, Terragrunt, GitHub Actions, target `both` | Complete Copilot tree (`.github/`) and Claude Code output (`CLAUDE.md`, `.claude/`) |

The `generated/azure-terragrunt` example contains the complete Copilot output
tree the CLI produces for a workspace with orchestration:

- `.github/copilot-instructions.md`
- `.github/agents/` — `infra-architect`, `terraform-module-builder`,
  `terraform-test-writer`, `terragrunt-stack-manager`
- `.github/instructions/` — `terraform-modules`, `terraform-tests`,
  `pipeline-templates`, `iac-best-practices`, `terragrunt-configs`
- `.github/skills/` — `create-terraform-module`, `create-infra-pipeline`,
  `create-terragrunt-stack`

## Illustrative examples (other `examples/*`)

The other directories are hand-authored output from the full `SKILL.md`
bootstrap procedure. They show a wider surface than the CLI generates and are
not regenerated by `build_examples.py`.

## Outputs the CLI does not generate

The CLI generates the core Copilot and Claude Code files. The following outputs
come from the `SKILL.md` procedure only and are intentionally omitted from CLI
output (they appear in the illustrative examples, not the reproducible ones):

- `.github/instructions/checkov.instructions.md`
- `.github/instructions/opa.instructions.md`
- `.github/instructions/tflint.instructions.md`
- `.github/instructions/terratest.instructions.md`
- `.github/agents/orchestration-coordinator.agent.md`
- `.claude/commands/coordinate-module-rollout.md`
- `maturity-report.md`
